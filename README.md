# Joke Settings

Small KDE / Fedora application for displaying jokes from
[JokeAPI](https://v2.jokeapi.dev/) using a Quote-of-the-Day Plasma widget.

The application provides a graphical interface for configuring:

- Languages
- Joke categories
- Blacklist flags
- Safe Mode
- Number of API requests

It automatically generates a fortune-style text file that can be used
by KDE Plasma Quote-of-the-Day widgets.
